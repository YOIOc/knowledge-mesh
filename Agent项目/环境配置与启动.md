## MySQL
```
# 下载镜像
docker pull mysql:5.7

# 创建数据卷
docker volume create mysql57-data

# 启动容器
docker run -d --name mysql57 -p 3306:3306 --restart unless-stopped -e MYSQL_ROOT_PASSWORD=12345678 -e MYSQL_ROOT_HOST=% -e TZ=Asia/Shanghai -v mysql57-data:/var/lib/mysql mysql:5.7 --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci
```
